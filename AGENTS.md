# AGENTS.md

## Repo Rules
- Stay inside this folder.
- Use `uv` with the local `.venv`.
- Keep the `uv` cache in `.uv-cache`.
- Install only the packages this repo needs.
- Keep code and scripts short and clear.

## Default Setup
- `UV_CACHE_DIR=.uv-cache uv venv`
- `UV_CACHE_DIR=.uv-cache uv sync --dev`
- `./test.sh`
